## Acceptance criteria
- [x] Кожен домен (`coins`, `bonds`) — окрема Postgres-схема
- [x] Жодних прямих FK між доменними схемами
- [x] Спільна колекція не містить `owner_id`
- [x] RLS для доменних таблиць перевіряє membership через `public.profiles`
- [x] Уся історія змін схеми — у вигляді послідовних міграцій у git, відтворювана з нуля
- [x] Перший користувач не зашивається в міграції як фіксований `admin/admin`; bootstrap виконується окремо й безпечно
- [x] Локальний старт (`supabase start`) автоматично застосовує всі міграції з `supabase/migrations/`
- [x] CI/CD автоматично застосовує нові міграції на production БД при мержі в `main` (GitHub Actions + Supabase CLI), без ручного кроку
