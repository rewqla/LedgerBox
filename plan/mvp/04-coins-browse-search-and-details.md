## Підзадачі
- [ ] Реалізувати collection page з двома режимами відображення
- [ ] Додати read queries для списку й детальної картки монети
- [ ] Реалізувати пошук за назвою
- [ ] Зафіксувати правило, що пошукова логіка належить тільки `src/features/coins/collection` і не виноситься в reusable shared helper без окремої потреби
- [ ] Дозволити реюз лише presentation-компонентів або стилів пошуку, але не доменної query/filter логіки
- [ ] Реалізувати фільтри за роком, категорією і дорогоцінним металом
- [ ] Підключити збереження view mode між сесіями
- [ ] Підготувати UI для 0/1/2 фото з окремими слотами аверс/реверс
- [ ] Додати або оновити інтеграційні та UI-тести для browse/search/filter flows

## Acceptance criteria
- [ ] Список усіх монет у двох режимах відображення: картки (фото + назва + рік) і таблиця
- [ ] Перемикання вигляду зберігається (localStorage / налаштування користувача)
- [ ] Пошук за назвою
- [ ] Пошукова логіка залишається специфічною для фічі монет і не реюзається між доменами
- [ ] Фільтр за роком, категорією та дорогоцінним металом
- [ ] Клік на монету відкриває детальну картку з усіма полями
- [ ] Монета може мати 0, 1 або 2 фото: окремі слоти для аверсу та реверсу
- [ ] Третє фото додати неможливо, оскільки окремої галереї / таблиці фото в MVP немає
- [ ] Кожен кінцевий файл фото у Storage ≤ 1 MB
